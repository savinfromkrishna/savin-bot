# Plan a Short

1. One idea per Short. Write the payoff first, then work back to the hook.
2. Hook (0–2 s): a claim, a question or a visual surprise. No intros, no "hey guys".
3. Body (3–45 s): 3 beats at most. One sentence per beat, each under 12 words, spoken naturally.
4. Payoff (last 3–5 s): deliver the promise of the hook; loop back to the first frame if possible.
5. On-screen text: 3–6 words per card, large, centred in the safe area (avoid the bottom 20%).

# Package

- Title: under 60 characters, the curiosity gap, no clickbait the video does not pay off.
- Description: 1–2 lines plus 3–5 hashtags, #shorts last.
- Save as `posts/<date>-<slug>/script.md` with sections: Hook, Beats, Payoff, On-screen text, Title, Description, Hashtags, B-roll ideas.
